# meal-prepper-app
a repository for an online meal-prepping application, with the following features:
- add individual ingredients
- add recipes, with information about serving sizes, prep/cook times, ingredients and steps 
- generate shopping lists on a weekly basis, allowing the user to select daily breakfast, lunch, and dinner meals from the stored lists and add their 
- view ingredients, recipes, and previously generated shopping lists

to be implemented:
- methods to read to/from data stores
- backend logic to construct a shopping list from a list of selected recipes + ingredients
- API contract
- BFF system with lambda functions
- frontend using typescript/react
